From text to diagram

Paste Mermaid. Or ask an AI for JSON.

The importer understands flowcharts and ER diagrams and lays them out for you. The whole Diagram is one JSON document with a reference written for AI — paste a fragment and it's added to the canvas.

  • Lines the importer doesn't understand become warnings — never an error.
  • Invalid JSON is repaired field by field and can never crash the canvas.
  • Auto-layout keeps Lines out of Elements and chains in straight lines.

Self-host

Your own instance on free tiers.

Firebase's free Spark plan plus Vercel is all it takes — no server code, no Cloud Functions. Security lives in Firestore rules shipped with the repo.

  1. 01

    Create a Firebase project

    Enable Google and Email/Password sign-in and Cloud Firestore.

  2. 02

    Deploy the rules

    firebase deploy --only firestore
  3. 03

    Import into Vercel

    Add the NEXT_PUBLIC_FIREBASE_* variables and deploy.

  4. 04

    Optional: lock it down

    Add an Access list of allowed email domains and grant administrators.
