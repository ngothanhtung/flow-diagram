# Lessons (Bài học) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cho người dùng tự soạn bài học từng bước (hình 2D của X Flow Tool + lời giảng) và chia sẻ qua Public link.

**Architecture:** Bài học là loại tài liệu riêng (`users/{uid}/lessons`, `public-lessons`), bên trong chứa một `FlowDocumentJSON` nguyên vẹn cộng phần `LessonContent` (meta, presence, steps). Logic bài học là các module thuần trong `src/lib/lesson/`. Trình soạn dùng lại `useEditorStore`: store có thêm nhánh `lesson` nằm trong snapshot Undo, và một bước "bookkeeping" trung tâm tự ghi `presence` cho Element mới. Canvas nhận thêm "look" theo từng Element (normal / emphasis / muted / ghost / gone) để làm mờ, nhấn mạnh và fade.

**Tech Stack:** Next.js 16 App Router (đọc `node_modules/next/dist/docs/` trước khi viết route — xem `AGENTS.md`), React 19, zustand, Tailwind 4, shadcn/ui trên Base UI, Firebase Auth + Firestore, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-21-lessons-design.md` (đọc cùng kế hoạch này).

## Review Focus

1. **Xoá một Element có `presence`/ghi đè rồi Undo**: Element quay lại cùng `presence` và ghi đè của nó, vì snapshot Undo chứa cả `lesson`. → test ở Task 6.
2. **Kéo đổi thứ tự làm `until` đứng trước `from`**: không crash; Element không hiện ở bước nào, nằm trong `presenceWarnings`, và trình soạn hiện cảnh báo. → test ở Task 3.
3. **Public link của một bài có tài liệu hỏng hoặc cũ** (thiếu `steps`, id bước trùng, `presence` trỏ tới Element không tồn tại, chương lạ): trang xem vẫn mở sau khi chuẩn hoá. → test ở Task 1.
4. **Lời giảng chứa `<script>`/`<img onerror>`**: hiện đúng dạng chữ. → test ở Task 4.
5. **Từ trình soạn bài học chuyển sang editor Diagram trong cùng một phiên SPA**: editor Diagram hiện đúng Diagram của nó; session `flowgram:session:{uid}` không bị ghi bằng nội dung bài học. → test ở Task 6 (`closeLesson` rồi `hydrate`).

    document: FlowDocumentJSON;               // diagram đã áp ghi đè (title/label/effect) của bước; KHÔNG bỏ Element nào
    looks: Record<string, ElementLook>;       // cho mọi node và edge id

  Số thứ tự bước trong hint đếm từ 1 theo thứ tự hiện tại.

- [ ] **Step 1: Viết test thất bại.** Fixture: các bước `s1,s2,s3,s4`; node `a`, `b`, Frame `f` chứa `c`; edge `ab` (a→b), `bc`.
  - `elements without presence are visible everywhere`.
  - `from/until is a half-open range in current step order`: `b:{from:'s2',until:'s4'}` → hiện ở s2, s3; không hiện ở s1, s4.
  - `a step's visible override wins over presence`: `b:{until:'s2'}` + `s3.overrides.b.visible=true` → hiện ở s3 nhưng không ở s2; `s1.overrides.a.visible=false` → `a` ẩn ở s1.
  - `a line needs itself and both ends visible`: `b` ẩn ở s1 → `ab` không hiện ở s1, dù `ab` không có presence.
  - `hiding a frame hides its members`: `f:{from:'s3'}` → `c` không hiện ở s2.
  - `entering elements are emphasised after the first step, the rest muted`: `b:{from:'s2'}` → ở s2 `looks.b==='emphasis'`, `looks.a==='muted'`; ở s1 không ai `emphasis`/`muted`.
  - `manual emphasis counts at any step`: `s1.overrides.a.emphasis=true` → `a` là `emphasis`, `b` là `muted`.
  - `hidden elements are ghost in the editor and gone in the viewer`.
  - `overrides change title, label and effect only in that step`: `s2.overrides.a={title:'X',effect:'glow'}`, `s2.overrides.ab={label:'L',effect:'none'}` → document của s2 có các giá trị đó, của s1 thì không.
  - `editor hints name the step`: `b:{from:'s3'}` ở s1 → `hints.b === 'From step 3'`.
  - `stepExportDocument keeps only visible elements and fades muted nodes`.
  - `lookStyle` đúng bảng giá trị ở trên.
  - `an unknown stepId resolves like the first step` (không throw).
